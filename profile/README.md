# Crono

Crono is a PostgreSQL-backed scheduler and execution control plane for infrastructure automation. Run jobs on demand, schedule them once, or set up recurring cron schedules. NATS JetStream dispatches work to scalable worker pools.

## Get started

- [Crono](https://github.com/crono-io/crono) — Source code, architecture, and local setup.
- [Helm charts](https://github.com/crono-io/crono-helm) — Deploy the control plane and web UI on Kubernetes.
- [crono.io](https://crono.io) — Project website.
